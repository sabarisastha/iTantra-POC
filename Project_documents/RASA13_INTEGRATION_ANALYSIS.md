# AI4Bharat Rasa-13 TTS Integration Analysis — iTantra

## 1. Executive Summary
This document details the architectural analysis and production integration strategy for the **AI4Bharat Rasa-13** multilingual Text-to-Speech (TTS) model into the **iTantra** Android application for **Smart India Hackathon (SIH) 2026**.

Rasa-13 provides high-quality VITS-based speech synthesis across 13 Indic languages. By integrating Rasa-13 behind the existing `TextToSpeechEngine` abstraction in iTantra, we achieve fully offline, low-latency multilingual speech synthesis across all required SIH Indic languages using a single shared model instance.

## 3. Core Architectural Principles

```text
                         ┌──────────────────┐
                         │  TTS Request     │
                         │ text + language  │
                         └────────┬─────────┘
                                  │
                                  ▼
                     ┌────────────────────────┐
                     │ TextToSpeechEngine    │
                     │ (IndicParlerTtsEngine) │
                     └───────────┬────────────┘
                                 │
                                 ▼
                     ┌────────────────────────┐
                     │ Language / Model       │
                     │ Router (ModelConfig)   │
                     └───────────┬────────────┘
                                 │
              ┌──────────────────┴──────────────────┐
              │                                     │
              ▼                                     ▼
       Indic languages                         English
       supported by Rasa                      dedicated model
              │                                     │
              ▼                                     ▼
        Rasa-13 VITS                          MMS VITS
        ONNX / INT8                           existing model
              │                                     │
              └──────────────────┬──────────────────┘
                                 │
                                 ▼
                         Sherpa-ONNX OfflineTts
                                 │
                                 ▼
                         GeneratedAudio (22050 Hz)
                                 │
                                 ▼
                            AudioPlayer
                                 │
                                 ▼
                             Speaker
```

### Key Highlights:
1. **Single Model Reuse**: The 9 Indic languages share the exact same ONNX binary (`models/tts/rasa13/model.onnx`). Switching between Hindi, Tamil, and Malayalam updates only the `speakerId` parameter, preserving the in-memory `OfflineTts` engine instance.
2. **Dynamic Sample Rate Handling**: Audio output generated by Rasa-13 runs at **22050 Hz**. The audio pipeline dynamically inspects `GeneratedAudio.sampleRate` and configures `AudioTrack` accordingly without hardcoding 16000 Hz.
3. **Alert Audio Focus**: Emergency / alert speech requests (`isAlert == true`) request transient exclusive audio focus (`AUDIOFOCUS_GAIN_TRANSIENT_EXCLUSIVE`) and set `STREAM_ALARM` to max volume, restoring previous volume levels upon completion.
